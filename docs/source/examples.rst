------------------
Examples
------------------

The examples below are available in the repository:

Inline Holography
~~~~~~~~~~~~~~~~~

- `inline_example.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/inline_example.py>`_ - Basic inline holography workflow using the Holo class.
- `inline_example_advanced.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/inline_example_advanced.py>`_ - Advanced inline holography workflow using the Holo class.
- `inline_example_using_prop_lut.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/inline_example_using_prop_lut.py>`_ - Inline refocusing using a propagator LUT.
- `inline_low_level_example.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/inline_low_level_example.py>`_ - Inline holography using lower-level functions.
- `inline_low_level_example_using_prop_lut.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/inline_low_level_example_using_prop_lut.py>`_ - Inline holography using a propagator LUT (low-level).

Off-Axis Holography
~~~~~~~~~~~~~~~~~~~

- `off_axis_example.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/off_axis_example.py>`_ - Basic off-axis holography workflow using the Holo class.
- `off_axis_example_refocusing.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/off_axis_example_refocusing.py>`_ - Off-axis refocusing example.
- `off_axis_example_refocusing_phase_vis.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/off_axis_example_refocusing_phase_vis.py>`_ - Off-axis refocusing with phase visualization.


Autofocusing
~~~~~~~~~~~~

- `autofocus_example.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/autofocus_example.py>`_ - Basic autofocus using the Holo class.
- `autofocus_example_advanced.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/autofocus_example_advanced.py>`_ - Advanced autofocus with ROI, margin, and PropLUT using the Holo class.
- `autofocus_example_low_level.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/autofocus_example_low_level.py>`_ - Basic autofocus using lower-level functions.
- `autofocus_example_low_level_advanced.py <https://github.com/MikeHughesKent/PyHoloscope/tree/main/examples/autofocus_example_low_level_advanced.py>`_ - Advanced autofocus with ROI, margin, and PropLUT using lower-level functions.
